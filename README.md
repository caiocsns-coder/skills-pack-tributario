# Skills Pack Tributário — Amostra Grátis

Duas skills prontas para o [Claude](https://claude.ai) atuar como seu assistente fiscal: uma para quem quer diagnosticar erros de NFS-e sem virar programador, outra para quem quer automatizar a rotina fiscal em Python.

Feito por [Caio Nascimento](https://www.linkedin.com/) — analista fiscal e desenvolvedor TaxTech.

## O que tem aqui

| Skill | Para quem |
|---|---|
| [`validador-nfse-basico/`](./validador-nfse-basico) | Analistas fiscais que querem entender rejeições de DPS/NFS-e sem depender de suporte |
| [`automacao-python-fiscal/`](./automacao-python-fiscal) | Quem quer automatizar rotina fiscal em Python, mesmo sem experiência prévia com código |

## Como instalar

**Claude.ai:** copie o conteúdo do `SKILL.md` da skill desejada e cole no início de uma conversa com o Claude, precedido de: *"A partir de agora, siga estas instruções ao me ajudar com temas fiscais:"*

**Claude Code / Claude Cowork:** copie a pasta da skill para dentro da pasta `skills` do seu projeto/ambiente. A skill é ativada automaticamente quando o contexto da conversa é compatível.
